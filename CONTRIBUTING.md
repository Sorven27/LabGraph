# Contributing to LabGraph

Thank you for helping improve LabGraph.

## Before opening an issue

- Check existing issues for a similar report.
- Include the browser and operating-system versions.
- For chart problems, attach a small project file or sample dataset when possible.
- Do not include private or sensitive experimental data.

## Development setup

No dependency installation is required for the web app. Open `index.html` or run a local static server.

Run the checks before submitting a pull request:

```bash
npm test
```

## Pull requests

- Keep changes focused.
- Preserve both English and Russian translations.
- Keep the printable chart independent of the interface theme.
- Test PDF, SVG, PNG, and project-file export when changing chart or persistence code.
- Update the README or changelog for user-visible changes.
