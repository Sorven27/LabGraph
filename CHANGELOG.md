# Changelog

All notable changes to LabGraph will be documented in this file.

## 1.0.0 — 2026-10-11

- Added experimental-data entry, CSV/TSV import, and project save/open.
- Added uncertainty bars and multiple regression modes.
- Added automatic horizontal and vertical mean lines.
- Added X/Y axis swapping and automatic/manual scaling.
- Added SVG, PNG, PDF, and CSV export.
- Added calibrated A4 graph paper in portrait and landscape modes.
- Added English and Russian interfaces, with English as the default.
- Added persistent dark and light themes, with dark as the default.
- Added macOS and Windows local launchers with clean shutdown.
