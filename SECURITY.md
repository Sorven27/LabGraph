# Security policy

## Supported version

Security fixes are applied to the latest version on the `main` branch.

## Reporting a vulnerability

Please use GitHub's **Private vulnerability reporting** feature instead of opening a public issue. Include clear reproduction steps and the affected browser or operating system.

LabGraph is a local-first static application. It does not require an account, backend, analytics service, or network API. The optional desktop launchers only serve the bundled static files on the loopback interface and use a per-session token for shutdown requests.
